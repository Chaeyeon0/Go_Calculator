# Go 문자열 덧셈 계산기

입력된 문자열에서 숫자를 추출하여 더하는 계산기

> 구분자(,, :, 커스텀 //;\\n)를 기준으로 숫자를 분리하고,
> 
> 
> 잘못된 입력(음수, 문자, 잘못된 구분자 등)을 검증하며
> 
> 결과를 출력하는 **Go CLI 애플리케이션**입니다.
> 

---

## 🗂️ 패키지 구조

```bash
gocalculator/
├── go.mod                 # Go 모듈 설정
├── calculator.go          # 합산(Sum) 로직
├── splitter.go            # 문자열 분리(SplitNumbers)
├── validator.go           # 유효성 검사(ValidateNumbers)
├── *_test.go              # 각 기능별 테스트
└── cmd/
    └── main.go            # CLI 진입점 (사용자 입력 및 결과 출력)

```

| 파일명 | 역할 |
| --- | --- |
| `splitter.go` | 문자열을 쉼표, 콜론, 커스텀 구분자로 분리 |
| `validator.go` | 입력된 문자열이 유효한 숫자인지 검사 |
| `calculator.go` | 정수 리스트를 합산 |
| `cmd/main.go` | 사용자 입력을 받아 계산 결과를 출력 |
| `*_test.go` | 각 기능별 단위 테스트 구현 |

## 🧩 기능 요구사항

### 1️⃣ 기본 구분자 처리

- 쉼표(`,`), 콜론(`:`)을 구분자로 사용
    
    ```bash
    "1,2:3" → 6
    ```
    

### 2️⃣ 커스텀 구분자

- 문자열 앞부분에서 `//`와 `\n` 사이 문자를 구분자로 지정
    
    ```bash
    "//;\n1;2;3" → 6
    
    ```
    

### 3️⃣ 빈 문자열 입력

- 아무 입력도 없을 경우 `0` 반환

### 4️⃣ 유효성 검사

- 음수 입력 시 → `"잘못된 입력: 음수는 허용되지 않습니다"`
- 숫자가 아닌 입력 시 → `"잘못된 입력: 숫자가 아닌 문자가 포함되어 있습니다"`
- 구분자 연속, 끝 구분자 등 잘못된 구조 시 → `"잘못된 입력: 구분자가 연속되었거나 잘못 배치되었습니다"`

### 5️⃣ 합산 결과 출력

```bash
덧셈할 문자열을 입력해 주세요:
1,2:3
결과 : 6

```

## ✅ 구현 흐름

| 단계 | 내용 | 테스트 예시 |
| --- | --- | --- |
| 1️⃣ `SplitNumbers` | 구분자를 기준으로 문자열 분리 | `"1,2:3"` → `["1","2","3"]` |
| 2️⃣ `ValidateNumbers` | 숫자 및 음수 검증 | `["1","-2"]` → error |
| 3️⃣ `Sum` | 정수 리스트 합산 | `[1,2,3]` → 6 |
| 4️⃣ `main.go` | CLI로 입력받아 결과 출력 | `"//;\n1;2;3"` → 결과 : 6 |

## 📘 예시 입력 / 출력

| 입력 | 출력 |
| --- | --- |
| `""` | 결과 : 0 |
| `"1,2:3"` | 결과 : 6 |
| `"//;\n1;2;3"` | 결과 : 6 |
| `"1,a,3"` | 에러: 잘못된 입력: 숫자가 아닌 문자가 포함되어 있습니다 |
| `"1,-2,3"` | 에러: 잘못된 입력: 음수는 허용되지 않습니다 |
